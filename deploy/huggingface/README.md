# Migration Agent

A client is moving from their old HR tools to a new platform. This agent reads their messy exports (CSV + Excel,
different column names, mixed date formats, duplicates, missing fields), works out the mapping to the target schema,
cleans and combines the records, and pushes them to the new platform's API **on its own** - stopping to ask a human
only when the data genuinely can't answer the question.

**Try it:** *New migration → Sample client export (first extract)*. It pauses on the two questions the data can't
settle, then pushes the rest. Resolve a card and watch the record flow through. Then run the *re-export* to see it
apply what it learned and send only what changed.

- Source, evaluation and write-up: https://github.com/umesh-chowdary-tech/ai-data-migration-agent
- The employee data is synthetic, generated by `scripts/generate_data.py`.
- This Space has no persistent storage, so runs and learned rules reset when it restarts.
